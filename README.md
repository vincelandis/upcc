# UPCC Asset Repository

This repo contains assets for the Upper Perkiomen Community Church website, upcconline.org.

## Admin
- lists website management administrative details like font theme, etc

## Banner
- contains source images and banner working files for website homepage banners

## Sermon Graphic
- contains youversion / church website header images and other sermon theme source images

## Sermon Slideshow
- contains presentations for sermon outline slideshows

## Slides
- contains customized infographics and working files for pre-service slides

## Staff
- contains working files and source images for staff profile photos
